# 锁屏 Widget

iOS 16+ 锁屏小组件配置与使用指南。

---

## 添加锁屏 Widget

### 步骤
1. 长按锁屏 →「自定义」
2. 选择锁屏样式
3. 点击「添加小组件」区域
4. 选择想要的 Widget

### 常用锁屏 Widget

| Widget | 说明 |
|--------|------|
| 天气 | 显示当前天气 |
| 电池 | 显示电量 |
| 提醒事项 | 显示今日待办 |
| 日历 | 显示下一个日程 |
| 快捷指令 | 一键执行快捷指令 |
| 手电筒 | 快速打开手电筒 |
| 相机 | 快速拍照 |

---

## 快捷指令 Widget

这是最实用的锁屏 Widget 之一：

```
1. 在快捷指令中创建你想要的指令
2. 长按主屏空白处 →「+」
3. 搜索「快捷指令」
4. 选择大小（小/中/大）
5. 添加到锁屏或主屏
```

---

## 自动化触发

结合「自动化」功能，可以实现智能 Widget：

| 场景 | 自动化 |
|------|--------|
| 连接 WiFi | 自动显示家庭 Widget |
| 到达公司 | 自动切换到工作 Widget |
| 晚上 10 点 | 自动切换到睡眠 Widget |
