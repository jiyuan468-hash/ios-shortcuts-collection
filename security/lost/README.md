# 丢失模式

手机丢失时一键启动保护流程。

---

## 功能

1. **立即锁定** — 远程锁定设备并留言
2. **定位发送** — 发送当前位置给指定联系人
3. **数据备份** — 触发 iCloud 备份
4. **证据收集** — 拍摄周围照片作为证据

---

## 快捷指令步骤

```
触发方式：Siri「我的手机丢了」或锁屏快捷入口

1. 播放锁定提示音
2. 在锁屏显示留言（"请联系 XXX"）
3. 开启查找我的 iPhone
4. 发送位置到指定联系人
5. 拍摄当前环境照片
6. 记录时间戳
```

---

## 注意事项

- 此快捷指令需要较高权限，建议在可信设备上运行
- 建议搭配「查找」App 一起使用
- 定期测试确保快捷指令正常工作
