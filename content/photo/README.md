# 照片处理

批量处理照片，提升出图效率。

---

## 功能

| 功能 | 说明 |
|------|------|
| 截图拼接 | 多张截图垂直拼接成长图 |
| 批量水印 | 给选中照片添加水印 |
| 批量压缩 | 压缩照片减小体积 |
| 一键发朋友圈 | 选图 → 自动排版 → 打开朋友圈发布页 |
| 照片去重 | 识别并删除相似照片 |

---

## 截图拼接

```
1. 选择多张截图
2. 按时间排序
3. 计算总高度（宽度统一）
4. 垂直拼接成一张图片
5. 保存到相册
```

---

## 注意事项

- 批量操作时注意存储空间
- 涉及隐私的照片建议本地处理，不上传云端
