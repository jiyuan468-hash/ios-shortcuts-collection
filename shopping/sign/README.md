# 多平台签到

一键完成淘宝、京东、拼多多等平台的每日签到。

---

## 快捷指令步骤

```
1. 打开淘宝 → 自动签到 → 返回
2. 打开天猫 → 自动签到 → 返回
3. 打开京东 → 京豆签到 → 返回
4. 打开拼多多 → 多多果园 → 浇水 → 返回
5. 打开饿了么 → 领豆 → 返回
6. 打开闲鱼 → 签到 → 返回
7. 汇总所有签到结果 → 显示通知
```

---

## 关键操作说明

### 打开 App 并执行操作
使用「打开 App」动作，配合「等待」动作确保页面加载完成

### 抓取签到结果
通过「获取网页内容」或「从剪贴板获取」提取签到文案

### 错误处理
每个操作后添加「如果失败则跳过」的判断，避免一个失败影响全部

---

## 自动化建议

**推荐时间**：每天 10:00（各平台签到刷新时间）

**路径**：自动化 → 特定时间 → 添加操作 → 运行快捷指令
