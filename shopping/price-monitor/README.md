# 价格监控

商品降价时自动通知你。

---

## 功能

1. 输入商品链接或搜索关键词
2. 设置目标价格
3. 定时检查当前价格
4. 价格达标时推送通知

---

## 实现方式

### 方式一：网页抓取
```
1. 获取商品价格网页内容
2. 用正则提取价格数字
3. 与目标价格比较
4. 低于目标价 → 发送通知
```

### 方式二：第三方 API
使用价格监控服务 API（如慢慢买、什么值得买）

### 方式三：浏览器自动化
通过 Safari 打开商品页面截图识别价格

---

## 快捷指令结构

```
输入：商品 URL / 商品名称
输入：目标价格
循环：每 2 小时检查一次
  ├─ 获取当前价格
  ├─ 比较价格
  └─ 若低于目标价 → 发送通知 + 停止循环
```
