---

## 使用方式

### 方法一：Siri 语音触发
> "嘿 Siri，早上好" → 自动运行早起 routine

### 方法二：自动化触发
快捷指令 →「自动化」→「创建个人自动化」→ 选择触发条件

### 方法三：锁屏/主屏快捷入口
添加到锁屏后，按下电源键直接触发

---

## 常见自动化场景

| 触发条件 | 自动执行 |
|----------|----------|
| 连接家中 WiFi | 关闭勿扰模式 + 播报日程 |
| 到达公司位置 | 自动开启工作模式 |
| 晚上 11 点 | 开启睡眠模式 + 发送"已就位"消息给家人 |
| 充电至 100% | 提醒"可以拔充电器了" |
| 低电量（20%） | 自动开启省电模式 + 通知电量 |
