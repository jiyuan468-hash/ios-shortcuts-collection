# 早起 Routine

一键启动清晨流程，不用逐个打开 App。

---

## 功能清单

1. **播报天气** — 今日温度、降水概率、穿衣建议
2. **播报日程** — 今日待办事项和会议
3. **播放音乐** — 自动播放晨间歌单
4. **刷新新闻** — 今日头条简报
5. **记录天气截图** — 保存到相册方便日后查看

---

## 快捷指令步骤

```
1. 获取当前天气
2. 获取今日日程（日历）
3. 获取未读消息数（微信/短信）
4. 朗读文本（天气 + 日程）
5. 播放音乐（指定歌单）
6. 显示通知
```

---

## 自动化设置

**触发方式**：每天固定时间（如 7:00）

**路径**：快捷指令 App → 自动化 → 创建个人自动化 → 特定时间 → 添加操作 → 运行快捷指令

**注意**：关闭"运行前询问"，实现全自动触发
