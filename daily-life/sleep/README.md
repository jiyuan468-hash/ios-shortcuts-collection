# 睡眠模式

帮助入睡和起床的自动化方案。

---

## 功能清单

1. **睡前准备** — 一键开启所有睡眠相关设置
2. **起床提醒** — 闹钟响起时自动播报天气和日程
3. **睡眠记录** — 记录就寝和起床时间

---

## 睡前准备流程

```
1. 开启勿扰模式（仅允许来电）
2. 开启夜览模式（减少蓝光）
3. 设置明天早上 7:00 闹钟
4. 播放助眠白噪音（持续 30 分钟自动停止）
5. 发送消息给家人："已就寝，晚安"
```

---

## 起床触发

**方式一**：闹钟停止时自动运行早起 Routine

**方式二**：Apple Watch 检测到起床动作自动触发

---

## 注意

- 建议在快捷指令中设置「如果已在睡眠模式则跳过」的判断
- 勿扰模式设置中保留「重复来电」选项，紧急电话可打通 3 次
