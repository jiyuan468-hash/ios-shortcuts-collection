# 晚间 Routine

下班回家的放松流程，自动切换手机状态。

---

## 功能清单

1. **关闭日间模式** — 降低屏幕亮度 + 开启深色模式
2. **播放助眠音乐** — 白噪音或轻音乐
3. **明日准备提醒** — 查看明日天气和日程
4. **关闭通知打扰** — 开启勿扰模式（可保留来电）
5. **记录今日心情** — 简单语音备忘录

---

## 快捷指令步骤

```
1. 获取明日天气
2. 获取明日日程
3. 设置屏幕亮度为 30%
4. 开启深色模式
5. 播放白噪音（指定音频文件）
6. 开启勿扰模式（保留收藏联系人来电）
7. 显示："今晚好好休息，明天加油！"
```

---

## 自动化设置

**触发方式 A**：每天固定时间（如 22:30）

**触发方式 B**：连接到家中 WiFi 时

**触发方式 C**：到达指定位置（家）时

---

## 进阶用法

- 配合 HomeKit 智能设备，同时控制灯光、窗帘
- 与「睡眠模式」联动，到点后自动进入睡眠追踪
