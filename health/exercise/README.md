# 运动打卡

记录每日运动数据，形成习惯。

---

## 功能

1. **记录运动** — 手动输入或自动从 Health App 获取
2. **目标设定** — 每日步数/卡路里目标
3. **打卡分享** — 生成打卡图片分享到社交App
4. **连续天数** — 记录连续运动天数

---

## 快捷指令步骤

```
开始运动：
1. 记录开始时间
2. 开启 Apple Watch 运动追踪

结束运动：
1. 记录结束时间
2. 从 Health App 获取运动数据
3. 更新打卡记录文件
4. 显示今日运动摘要
5. 询问是否分享打卡图片
```

---

## 打卡图片生成

```
1. 获取今日运动数据
2. 加载打卡模板图片
3. 合成文字和数字
4. 保存到相册
5. 可选择分享到微信/朋友圈
```
