# 喝水提醒 快捷指令

**指令名称**：喝杯水

**触发方式**：手动点击 / 每小时自动化

---

## 数据存储

在「文件」App 创建 `water.json`：

```json
{
  "date": "2024-01-15",
  "count": 3,
  "goal": 8,
  "logs": ["08:30", "10:15", "12:00"]
}
```

---

## 快捷指令步骤

**记录喝水：**

| 步骤 | 动作 | 参数 |
|------|------|------|
| 1 | 读取文件 | `water.json` |
| 2 | 获取当前时间 | 格式：HH:mm |
| 3 | 追加到列表 | 时间加入 logs |
| 4 | 设置变量 | count + 1 |
| 5 | 写入文件 | 更新 water.json |
| 6 | 计算进度 | `count / goal` 百分比 |
| 7 | 显示通知 | 标题：💧 喝水提醒 / 内容：今日已喝 {{count}}/{{goal}} 杯 |
| 8 | 播放声音 | 提示音 |

**定时提醒自动化：**

| 触发条件 | 特定时间 → 每 60 分钟 |
| 执行动作 | 运行「喝杯水」快捷指令 |
| 条件判断 | 若 count < goal 则发送通知 |

---

## 进度语参考

| 进度 | 鼓励语 |
|------|--------|
| 1-2 杯 | 刚开始，继续加油！ |
| 3-5 杯 | 不错，已经过半了！ |
| 6-7 杯 | 快完成了，再来一杯！ |
| 8 杯 | 🎉 今日目标达成！ |
