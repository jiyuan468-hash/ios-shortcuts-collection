# 喝水提醒

养成每天喝够 8 杯水的习惯。

---

## 功能

1. **记录喝水** — 每喝一杯水点击记录
2. **定时提醒** — 每小时提醒喝水
3. **进度展示** — 显示今日完成进度
4. **每日报告** — 睡前推送今日喝水总结

---

## 实现方式

使用快捷指令的「文件」存储每日喝水记录：

```
存储格式（tasks.json）：
{
  "date": "2024-01-15",
  "count": 5,
  "goal": 8,
  "logs": ["08:30", "10:15", "12:00", "14:30", "16:45"]
}
```

---

## 快捷指令步骤

```
添加一杯水：
1. 读取今日记录文件
2. count + 1
3. 记录时间到 logs
4. 保存文件
5. 显示进度 + 鼓励语

定时提醒：
1. 每 60 分钟触发
2. 读取今日已喝数量
3. 若少于目标 → 发送通知
```
