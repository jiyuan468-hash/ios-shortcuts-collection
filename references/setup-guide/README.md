# 快捷指令使用教程

从零基础到熟练使用快捷指令。

---

## 一、基础概念

### 什么是快捷指令？

快捷指令（Shortcuts）是 iOS 自带的自动化工具，可以将多个操作组合成一个指令，一键执行。

### 核心术语

| 术语 | 说明 |
|------|------|
| 动作（Action） | 最小执行单元，如「获取天气」 |
| 变量 | 存储中间数据 |
| 输入/输出 | 动作之间的数据传递 |
| 参数 | 动作的配置选项 |

---

## 二、创建你的第一个快捷指令

### 步骤

1. 打开「快捷指令」App
2. 点击右上角「+」
3. 点击「添加动作」
4. 搜索你需要的操作（如「获取天气」）
5. 添加更多动作，按顺序排列
6. 点击「播放」测试
7. 命名并保存

### 示例：早安播报

```
1. 获取当前天气
2. 获取今日日出时间
3. 获取今日日落时间
4. 组合文本："早上好！今天天气 {天气}，日出 {日出}，日落 {日落}"
5. 朗读文本
```

## 三、设置自动化

### 什么是不需要手动触发的快捷指令？

自动化 = 满足条件时自动运行快捷指令。

### 触发类型

| 类型 | 说明 |
|------|------|
| 特定时间 | 每天固定时间 |
| App 打开 | 打开某个 App 时 |
| 到达/离开位置 | GPS 定位触发 |
| 连接 WiFi | 网络触发 |
| 充电状态 | 电量/充电触发 |
| 电池电量 | 低电量提醒 |

### 设置步骤

1. 快捷指令 App →「自动化」标签
2. 点击「创建个人自动化」
3. 选择触发条件
4. 添加操作（运行快捷指令）
5. **关闭「运行前询问」**（实现全自动）

## 四、添加到主屏和锁屏

### 主屏快捷方式

1. 快捷指令 → 点击指令名称
2. 点击右上角「...」
3. 选择「添加到主屏幕」
4. 设置图标和名称
5. 点击「添加」

### 锁屏快捷入口（iOS 16+）

1. 长按锁屏 →「自定义」
2. 选择锁屏样式
3. 点击「其他快捷方式」
4. 选择你想放在锁屏的快捷指令
5. 完成

## 五、常用动作速查

### 常用动作类别

| 类别 | 常用动作 |
|------|----------|
| 脚本 | 获取当前日期、获取设备信息 |
| 变量 | 设置变量、获取变量、显示变量 |
| 文本 | 获取输入、组合文本、查找文本 |
| 网页 | 获取 URL 内容、打开 URL |
| 媒体 | 播放音频、播放视频、拍摄照片 |
| 通知 | 发送通知、显示对话框 |
| App | 打开 App、获取 App 信息 |
| 数学 | 随机数、计算 |
| 列表 | 新建列表、添加条目 |
| 条件 | 如果...则...、循环 |

## 六、进阶技巧

### 1. 条件判断

```
如果（天气 == "下雨"）
  则 → 提醒带伞
否则
  则 → 提醒防晒
```

### 2. 循环操作

对列表中的每个元素执行相同操作，如批量处理照片。

### 3. 错误处理

在动作后添加「如果失败则」分支，确保流程不中断。

### 4. 共享快捷指令

- 导出为 `.shortcut` 文件分享给朋友
- 从链接导入（以 `shortcuts://` 开头）
- 加入快捷指令社区交流

---

## 七、最佳实践

1. **保持简洁** — 一个快捷指令做一个事情
2. **命名清晰** — 用动词开头命名，如「添加任务」「查看天气」
3. **测试充分** — 正式发布前充分测试各种情况
4. **备份重要指令** — 导出 `.shortcut` 文件保存
5. **定期清理** — 删除不再使用的快捷指令

---

## 八、常见问题

**Q: 快捷指令运行失败怎么办？**
A: 检查网络连接、App 权限、变量是否正确赋值。

**Q: 如何让快捷指令自动运行不弹窗？**
A: 在自动化设置中关闭「运行前询问」。

**Q: 快捷指令能替代 App 吗？**
A: 部分可以，但复杂功能仍需专用 App 支持。
