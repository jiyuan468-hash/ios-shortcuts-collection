# 文件整理

自动整理相册、文档和下载文件夹。

---

## 功能

| 功能 | 说明 |
|------|------|
| 相册清理 | 删除模糊/重复截图 |
| 文件归类 | 按类型/日期整理下载文件夹 |
| 照片备份 | 自动备份到 iCloud/Google Photos |
| 截图拼接 | 长截图自动生成 |

---

## 相册清理流程

```
1. 获取最近 7 天截图
2. 筛选重复图片（按哈希值）
3. 标记待删除的模糊图片
4. 询问确认后删除
5. 生成清理报告
```

---

## 截图拼接

```
1. 选择多张截图
2. 按时间顺序排列
3. 垂直拼接成一张长图
4. 保存到相册
```
