# 会议纪要

会议结束后一键生成结构化纪要。

---

## 功能

1. 录音转文字（使用 iOS 自带转录或第三方服务）
2. 提取关键信息（时间、地点、参会人、议题）
3. 生成结构化纪要模板
4. 保存到备忘录或发送到邮箱

---

## 快捷指令步骤

```
1. 开始录音（会议开始时）
2. ... 会议进行中 ...
3. 停止录音
4. 将音频转为文字（使用转录动作或外部 API）
5. 用 AI 提取关键信息（调用 ChatGPT API）
6. 生成纪要格式
7. 保存到备忘录 / 发送到邮箱
```

---

## 注意事项

- iOS 内置转录功能仅支持部分语言
- 高精度转录建议使用外部服务（如讯飞、Azure Speech）
- 涉及保密会议请注意数据安全
