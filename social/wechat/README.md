# 微信快捷指令

微信虽然限制较多，但仍有不少实用场景。

---

## 可用功能

| 功能 | 说明 | 实现方式 |
|------|------|----------|
| 快速发起群聊 | 一键创建指定联系人组成的群聊 | 通过 URL Scheme |
| 批量发送消息 | 给多个联系人发送相同消息 | 循环+打开App |
| 消息汇总 | 汇总今日未读消息数 | 通知中心读取 |
| 转账备注 | 快速填写转账备注 | 粘贴板操作 |

---

## URL Scheme（部分）

```
weixin://                  # 打开微信
weixin://dl/moments        # 打开朋友圈
weixin://dl/feedback       # 意见反馈
weixin://dl/settings       # 设置
weixin://dl/games          # 游戏
weixin://dl/officialaccounts # 公众号
```

---

## 限制说明

- iOS 对微信 URL Scheme 限制严格，很多功能无法自动化
- 不建议尝试破解或修改微信，有封号风险
- 优先使用官方支持的快捷指令操作
